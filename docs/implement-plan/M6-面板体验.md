# M6 实施计划:面板体验——从流水账到阶段流转视图(自托管第六阶段)

> 上游文档:docs/implement-plan/M5-可观测性.md(数据面与面板已上线)、docs/architecture.md §2.10(观测面链路)
> 关联 issue:#3(已收官)| 状态:**草案(2026-11-15,调研已完成,待评审后开工)**
> 目标一句话:列表一眼知健康,详情一眼知"走到哪、卡在哪、时间花在哪",实时看站间流转——把 M5 的文字流水账升级为直观的生命周期阶段视图。

## 范围

**做**:管线图视图(四站+交付里程碑的流转图,含评审返工回边)、甘特视图(时间比例轴,与管线图一键切换)、列表行迷你管线升级、实时流直接驱动视图状态机、站级结构化摘要字段入记录(白名单)、M6 批次评审循环与文档回写。
**不做**:面板写操作与审批操作(respond,列 M7 候选);多仓聚合;引入前端构建链或外部 UI 库(零依赖内联单页红线,复杂度超限才重评);第三方观测平台(Langfuse/Grafana 等,内容出境违反 metadata-only 边界,M5 已按条款放弃 OTel 同理);agent 行为与信任模型改动(站级摘要由 run_ 工具 wrapper 落,不改站点指令)。

## 调研结论(2026-11-15,实查)

| 参照 | 形态 | 借鉴点 |
|------|------|--------|
| Vercel Agent Runs(eve 原生,官方同类) | 列表(触发消息/类型/token/轮数/时长)→ 详情逐轮分解(每步计时、工具调用、token);**子代理内联在派发轮下、共享时间轴、行显时长与失败、点开钻取全量** | 信息架构(列表→详情→钻取);"站=子代理行内联共享时间轴"的呈现;逐步计时 |
| Langfuse trace 视图(2025-03 重设计) | **时间轴/树双形态切换**(chronological vs hierarchical),双形态指标对等;按类型/ID/名搜索;可选颜色编码 | "结构视图(管线)与时间视图(甘特)并存、一键切换、信息量对等"的双形态设计 |
| GitLab CI | 管线图(阶段列+节点+连线)+ **mini graph**(按阶段分组的点串,嵌在 MR/提交等一切列表处) | 迷你管线芯片放列表行;大图放详情顶部 |
| Airflow | Grid(runs×任务矩阵)+ Gantt(单 run 各任务起止/时长/并行) | 甘特=单 run 时间分布的正统形态;Grid 矩阵我们量小不采用 |
| Temporal | 事件史 + Timeline 视图(2023-10) | 事件时间线(M5 实时区已有雏形,保留为钻取层) |
| Jenkins Blue Ocean | 阶段流图,当前阶段动画强调 | 当前站呼吸态/进行中动效 |

## 现状差距(对照 M5 数据面)

- **够用的**:stages[](每站 startedAt/completedAt/durationMs/tokens/outcome,同名多轮已按 action 分条——评审返工可归轮);inputRequests(审批等待区间);turnFailures/actionErrors(失败点);status 终态+prUrl+thread;实时流的 subagent.called(含 childSessionId 与站名)/action.result(turn 事件足以驱动"当前在哪站"状态机)。
- **缺的**:①视觉层——stage-dots 是五个字母块,无连线、无时间比例、无返工环;②站级语义摘要——metadata-only 让面板"知道多久、不知道干了啥"(站点本就有 outputSchema 结构化产出:analyst 计划标题、reviewer verdict、implementer 分支名,属结构化元数据而非对话内容);③编排器自身耗时(站间空隙)不可见——甘特留白即见,无需新数据;④轮次归组逻辑(前端可算)。

## 风险与应对

| 风险 | 症状 | 应对 |
|------|------|------|
| T1 白名单被评审认定为变相内容落盘 | 边界争议 | 只落"工具结构化输出"字段(站点 schema 本就是给编排器消费的机读数据),不落任何自由文本正文;争议字段撤出白名单 |
| 内联单页膨胀失控 | dashboard.ts 单文件超 ~1500 行 | 先拆 runPanelPage 为多段模板函数(仍单文件);仍超限再评估静态资产方案(需查 eve channel 静态文件机制),引入构建链仍属红线 |
| 管线图在长 run(多轮返工)溢出 | 回边/徽标挤压 | 返工 ≥3 轮折叠为"N 轮"徽标,甘特承担细节 |
| 实时状态机与记录面对账闪烁 | 流事件与轮询数据短暂不一致 | 以记录面为收敛权威,流事件只做即时插值(现有 30 秒收敛机制复用) |
| pm2 环境缓存复发 | 新代码不生效 | 守 M4 规矩:delete + 干净 shell start + save |
