> 目标一句话:剥 Linear、路由鉴权换 Basic、WSL2 + pm2 常驻——工厂从"开着 TUI 才活着"变成"开机即在的服务",Windows 侧远程连入可用。

## 范围

**做**:Linear 全剥离、`eve start` 生产形态的路由 Basic 鉴权、WSL2 内 `eve build && eve start` + pm2 守护 + 开机自启、Windows 侧 `eve remote connect` 接入验证、两项 M1 遗留运维项(maxOutputTokens 消音调查、孤儿容器巡检)。
**不做**:webhook 与公网隧道(M3)、沙箱自建镜像(M3)、FACTORY_REPO 切换(仍 local-factory-dev,切换协议 M3 执行)、Blob 本地后端(M1 已提前完成)。

## 关键事实(已核实,实施依据)

- **`eve start` 下现行鉴权全灭**:`localDev()` 只在 `EVE_DEV=1`(即 `eve dev`)时认证,`vercelOidc()` 无 Vercel 项目环境必拒——eve 生产默认 fail closed(auth-and-route-protection.md)。不换 Basic,常驻服务一个合法请求都进不来。
- **Basic 官方 helper**:`httpBasic({ username, password }, { realm? })`,恒时比较、NFC 归一化,401 自动带 `WWW-Authenticate: Basic realm=...`;凭据走 env(文档示例名 `ROUTE_AUTH_BASIC_PASSWORD`),不入编译产物。
- **health 路由公开**:`/eve/v1/health` 跳过鉴权走查,拨测无需凭据。
- **`eve start` 不加载 `.env.local`**(M1 实测:仅 dev 命令加载)——常驻形态 env 注入必须自建(wrapper 或 pm2 env_file,实施时核实 start 是否吃 `.env.production`)。
- **工作流状态目录** `.eve/.workflow-data` 默认本地盘,pm2 重启不丢;两个数据目录(`.eve/.workflow-data`、`FACTORY_DATA_DIR`)必须落在 WSL2 原生文件系统(ext4),不放 /mnt/d(NTFS I/O 慢、锁语义怪)。
- **代理路由前缀**:`/eve/` 与 `/.well-known/workflow/` 都要可达(M3 隧道时用;M2 内网直连无此问题)。
- **maxOutputTokens 消音无公开杠杆**:eve 公开 selection 对象只有 `{model, reasoning, modelContextWindowTokens, modelOptions}`,`maxOutputTokens` 仅存在于内部引用(网关目录填充);外部 provider 对象路径下未设置 → @ai-sdk/anthropic 对未知模型 glm-5.3 默认 4096 并告警。消音路径需实施时调查(见 T7)。

## 风险与应对

| 风险 | 症状 | 应对 |
|------|------|------|
| `eve start` env 注入姿势不明 | 服务起来但 FACTORY_REPO 未设、模块加载报错 | T3 先实测 start 加载行为;不加载则 wrapper `set -a` source,与 M1"脚本注入 env"同纪律 |
| remote connect 凭据传法不明 | 连接 401 | `eve remote connect --help` 核实(URL 内嵌 / header / token 参数);再不行临时 curl 会话 API 证明 Basic 通,remote connect 侧另查 |
| WSL 开机不自启 | Windows 重启后服务没回来 | 计划任务 `wsl -d <distro> true` 唤起;systemd + pm2 startup 接力;验收清单含整链演练 |
| localhost 转发失效 | Windows 侧 curl 不通 | 查 wsl.conf / mirrored networking;兜底直连 WSL IP(固定虚拟交换机或镜像网络) |
| Basic 明文过内网 HTTP | 凭据嗅探面 | 密码长随机;仅监听内网;M3 隧道化后自动获得 HTTPS;不做公网暴露 |
| httpBasic principalType 非 user | 远程会话 user-preferences 工具不可用 | T2 核实;非 user 则记录行为(偏好功能降级为 dev-only,不阻塞) |
| WSL 内 docker 权限 | docker.sock permission denied | Docker Desktop 集成开关重开;或 usermod -aG docker |
| 剥 Linear 后遗漏引用 | validate/发现期报错 | 删后 grep 三连(linear / LINEAR / @vercel/connect)+ validate;evals 已确认零 Linear 用例 |
| glm-5.3 告警无解 | 每站刷 4096 兼容告警 | T7 调查;兜底 pm2 日志过滤;纯噪音不阻塞任何验收项 |
