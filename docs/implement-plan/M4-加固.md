## 风险与应对

| 风险 | 症状 | 应对 |
|------|------|------|
| 修复环不派发 | 红套件无反应 | 先核 App 的 check_suite 订阅与 Actions 套件的 head_branch 事件形态;用 gh api 手查 delivery |
| 修复环过冲 | 反复修复反复红 | attempt 封顶机制实测;观察计数评论是否生效 |
| GH Actions 拨测误报 | 边缘偶发超时 | 连续 2 次失败才 fail;30 分钟粒度容忍短抖 |
| 备份把盘打满 | /data 增长 | 14 份轮转上限;首跑后核体积(数据目录现 <100MB 量级) |
| 断电演练丢在途轮 | run 状态不可续 | 预期接受(记录真实行为);issue 线程可再推即满足恢复口径 |
| e2e 直跑代价大 | conftest 深耦合显示/服务 | 记录放弃,不为验收硬改 |
