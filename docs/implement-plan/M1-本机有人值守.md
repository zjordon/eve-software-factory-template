# M1 实施计划:本机有人值守(自托管第一阶段)

> 上游文档:docs/自托管实施方案.md(M1 节)、docs/architecture.md(§2.6 凭据与沙箱)
> 关联 issue:#1 | 分支:feat/self-hosting | 状态:待实施
> 目标一句话:BYO GitHub App + 本地 TUI,四站流水线全本地跑通,产出真实草稿 PR。零公网、零隧道、不动 Linear(M2 才剥)。

## 范围

**做**:自建 GitHub App、通道凭据换 BYO、安装令牌适配、专用测试仓库、本地 TUI 全流水线验证。
**不做**:webhook(M3)、剥 Linear(M2)、Blob 本地后端(M3)、沙箱自建镜像(M3)、路由鉴权更换(M2)。

## 前置条件(开工前逐项确认)

- [ ] Docker Desktop 已启动(`docker info` 正常应答;站点沙箱依赖它,M1 用 eve 默认镜像)
- [ ] Node 24.x + pnpm 就绪(本机已具备)
- [ ] gh CLI 已登录(建测试仓库用)
- [ ] 机器可出站访问 api.github.com 与 open.bigmodel.cn

## 任务分解

### T1 建专用测试仓库(仓库切换协议的落地)

```powershell
gh repo create zjordon/local-factory-dev --public --add-readme
```

- 用途:M1/M3 全部验收在此仓库进行,**绝不安装到 examination-system**(云端 examiner 还在那服务,双 App 同仓库 = 串线)
- 预期:空仓库创建成功,可见 README
- 回滚:验收后可整个删除

### T2 自建 GitHub App(BYO)

入口:`github.com/settings/apps/new`,逐字段:

| 字段 | 值 |
|------|------|
| GitHub App name | `zjordon-foreman-local`(全局唯一) |
| Homepage URL | `https://github.com/zjordon/eve-software-factory-template` |
| Webhook → Active | **M1 不勾**(无 URL 可填;M3 隧道就绪后再激活并配 secret) |
| Repository permissions | Actions/Checks/Contents/Commit statuses/Deployments/Environments/Issues/Packages/Pages/Pull requests/Workflows = **Read & write**;Metadata = Read-only(强制) |
| Subscribe to events | Issues / Issue comment / Pull request / Pull request review comment / Check suite(M3 才真正用到,先配齐无害) |
| Where can this app install | Only on this account |

创建后三件事:

- [ ] 记下 **App ID**(设置页顶部)
- [ ] 页面底部 **Generate a private key** → 下载 `.pem`,存到仓库外(建议 `D:\dev\git\z_jordon\secrets\zjordon-foreman-local.pem`)
- [ ] 安装 App 到 **T1 的测试仓库**(Only select repositories → 只勾 local-factory-dev);安装后从安装页 URL 记下 **Installation ID**(格式 `/settings/installations/<数字>`)

### T3 通道凭据换 BYO(代码改造,改动面最小的一版)

- [ ] `agent/channels/github.ts`:credentials 从 Connect 句柄改为 BYO 块(appId / privateKey / webhookSecret 走 env 或 lazy resolver),`botName: "zjordon-foreman-local"`(BYO 下不再从连接器解析);onIssue/onComment/onCheckSuite/onPullRequest 钩子**一行不动**
- [ ] `agent/lib/github/credentials.ts`:现实现读 `GITHUB_CONNECTOR` 走 Connect;改为从 App 凭据铸造安装令牌——App JWT(RS256,Node 原生 crypto 签 PEM)→ `POST /app/installations/<id>/access_tokens` → 1 小时安装令牌,带过期缓存;保持导出形状不变(`mintInstallationToken` 的消费方:push_branch / checkout_branch / repo-sandbox 全部无感)
- [ ] 私钥读取:env 放**路径**(`GITHUB_APP_PRIVATE_KEY_PATH`),lazy resolver 里 `fs.readFileSync`;避免多行 PEM 塞 env 的转义地狱
- [ ] 若通道在无 webhookSecret 时加载报错(M1 无 webhook):`.env.local` 放占位值 `GITHUB_WEBHOOK_SECRET=local-dev-placeholder`,Webhook 未激活则永不校验
- [ ] `pnpm fix` + 注入 env 后 `pnpm validate` 全绿(M1 仍需 `LINEAR_CONNECTOR` 等——Linear 是 M2 才剥离,模块加载期仍要求它)

### T4 环境变量(.env.local,M1 形态)

```ini
FACTORY_REPO=zjordon/local-factory-dev
FACTORY_LABEL=factory
ZHIPU_API_KEY=<已有>
GITHUB_APP_ID=<T2 记录>
GITHUB_APP_PRIVATE_KEY_PATH=D:\dev\git\z_jordon\secrets\zjordon-foreman-local.pem
GITHUB_INSTALLATION_ID=<T2 记录>
GITHUB_WEBHOOK_SECRET=local-dev-placeholder
GITHUB_APP_SLUG=zjordon-foreman-local
LINEAR_CONNECTOR=linear/linear        # M1 占位,M2 剥离后删除
```

私钥文件绝不进仓库(.gitignore 已覆盖 .env*;secrets 目录在仓库外)。

## 风险与应对

| 风险 | 症状 | 应对 |
|------|------|------|
| Docker Desktop 未启动 | 站点命令落到 just-bash(虚拟 FS,跑不了真 git),实现站报怪错 | 开工前 `docker info`;TUI 日志确认沙箱 provider 为 docker |
| JWT/安装令牌铸造失败 | T5 冒烟 401/403 | 核对 App ID、Installation ID、PEM 路径;用 gh 手工复现 `POST /app/installations/<id>/access_tokens` 排除代码问题 |
| 无 webhookSecret 加载报错 | 通道初始化失败 | 占位 secret(T3 已预案) |
| 默认镜像缺工具 | uv/Python 仓库的任务失败 | M1 只派 hello 级任务;uv 类需求等 M3 自建镜像 |
| evals needs-connect 失败 | `pnpm eval` 红 | 该标签用例改手动验证清单,不阻塞 M1 |
